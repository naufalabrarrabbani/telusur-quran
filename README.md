# Telusur Qur'an — by HijaLearn

Mesin penelusuran Al-Qur'an berbasis akar kata, graf entitas, dan galeri cek klaim.

**quran.hijalearn.id**

## Stack

- Next.js 15 (App Router, Static Export)
- Tailwind CSS v4
- TypeScript
- Deploy: Vercel

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Static output goes to `out/` — ready for Vercel deployment.
